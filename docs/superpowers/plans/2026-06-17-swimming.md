# Half-Life Swimming + Sharking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add faithful Half-Life water movement (`PM_WaterMove`) and the emergent "sharking" surface tech to the HalfLifeMovement mod.

**Architecture:** Pure GoldSrc water math goes in `HLMovementCore::WaterMove` (unit-tested). The existing `CalcVelocity` before/`_AFTER` hook pair gains a `MOVE_Swimming` branch that builds a 3D wish (swim where you look, bhop key = ascend, idle = sink) and applies `WaterMove`. Sharking is emergent: a surface breach impulse (gated to near-surface + bhop key) pops you out to `MOVE_Falling`, where the existing air-accel + auto-bhop already own movement. The engine's swim up-velocity clamp is defeated by raising `MaxSwimSpeed`.

**Tech Stack:** Unreal Engine (C++), SML native hooks on `UFGCharacterMovementComponent`, UE automation tests.

## Global Constraints

- **Hooks install only under `if (!WITH_EDITOR)`** — the mod is inert in PIE/editor. Engine-coupled behavior is verified in the packaged game via **Alpakit**, not the editor. Only `HLMovementCore` (pure math) is unit-testable.
- **Every feature toggle/tunable = a field in `FHLMovementSettings` + a bound `HL.*` CVar + a Save/Load line + a `HL.Dump` entry.** (Repo convention.)
- **Pure math lives in `HLMovementCore`; engine-coupled glue lives in `HLMovementHooks.cpp`.**
- Local-player gating via the existing `HLIsLocalPlayerMovement`; bhop key via the existing `HLBhopHeld` (all bhop jumping routes through the bhop key).
- Spec: `docs/superpowers/specs/2026-06-17-swimming-design.md`. Reference model: HL1 `pm_shared.c :: PM_WaterMove`.
- Commit to the mod repo (`Mods/HalfLifeMovement`, its own git repo) on `main`, direct linear commits. End commit messages with the `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>` trailer.

```cpp
    FVector WaterMove(const FVector& Velocity, const FVector& WishDir, float WishSpeed, float Accel, float Friction, float DeltaTime)
    {
        // Faithful PM_WaterMove. Unlike ground/air, this acts on the FULL 3D velocity and uses
        // proportional friction with NO stop-speed floor (the floaty water deceleration). Accel then
        // brings total speed toward WishSpeed along WishDir (WishDir is assumed already normalized).
        FVector V = Velocity;
        const float Speed = V.Size();
        float NewSpeed = 0.0f;
        if (Speed > 0.0f)
        {
            NewSpeed = Speed - DeltaTime * Speed * Friction;
            if (NewSpeed < 0.0f) { NewSpeed = 0.0f; }
            V *= (NewSpeed / Speed);
        }
        const float AddSpeed = WishSpeed - NewSpeed;
        if (AddSpeed <= 0.0f) { return V; }
        float AccelSpeed = Accel * WishSpeed * DeltaTime;
        if (AccelSpeed > AddSpeed) { AccelSpeed = AddSpeed; }
        V += AccelSpeed * WishDir;
        return V;
    }
```

```cpp
                else if (Self->MovementMode == MOVE_Swimming && S.bSwim)
                {
                    // HL PM_WaterMove. Wish direction is the 3D input (GetCurrentAcceleration is NOT
                    // gravity-flattened while swimming, so looking down+forward dives). Bhop key = swim
                    // straight up (ascend); fully idle = drift down. Then WaterMove on the full 3D velocity.
                    const float SwimSpeed = S.Params.MaxSpeed * S.WaterMaxSpeedScale;
                    FVector Wish = Self->GetCurrentAcceleration(); // 3D in water
                    const bool bUp = HLBhopHeld(Self, S);
                    const bool bIdle = Wish.IsNearlyZero() && !bUp;
                    FVector WishVel = Wish.GetSafeNormal() * SwimSpeed;
                    if (bUp) { WishVel.Z = SwimSpeed; }                               // ascend
                    else if (bIdle && S.bWaterSink) { WishVel = FVector(0, 0, -S.WaterSinkSpeed); } // drift down
                    const float WishSpeed = FMath::Min(WishVel.Size(), SwimSpeed);
                    const FVector WishDir = WishVel.GetSafeNormal();
                    NewVel = HLMovementCore::WaterMove(OwnVel, WishDir, WishSpeed,
                        S.WaterAccelerate, S.WaterFriction, Dt);

                    // ceiling sits comfortably above our swim/breach speeds. (Buoyancy stays at its neutral
                    // default so gravity is cancelled underwater; our vertical wish drives up/down instead.)

                }
                else // MOVE_Falling — horizontal only; gravity stays vanilla (handled in PhysFalling)
```
